# README — только витрина

README читают, чтобы за минуту понять проект. Цель — меньше 6 КБ.

**Что в нём есть (и только это):**
1. Что за проект — 2–3 предложения.
2. Быстрый старт — команды установки и запуска.
3. Команды — таблица «команда → одна строка».
4. Конфиги — таблица «где лежит → что там».
5. Структура — дерево каталогов и модулей, по строке на группу.
6. Секреты — 1–2 предложения (на заголовок «🔒 Секреты: что и куда не уходит»
   ссылается `.github/ISSUE_TEMPLATE/config.yml`).

**Чего в нём нет:**
- подкапотной логики: алгоритмы, каскады, веса, форматы таблиц, нити демона;
- описаний UI, кнопок, вёрстки страницы;
- полного списка `ND_*` — ссылка на `ENV_MAP` в `newsdigest/config.py`;
- troubleshooting, FAQ, истории изменений, «почему так сделано».

**Правила:**
- Любой раздел — не больше пары предложений или одной таблицы/блока кода.
- Новая фича попадает в README, только если меняет пункты 2–5 (новая
  команда, конфиг, модуль) — и одной строкой. Подробности — в docstring
  модуля или `--help` команды.
- Перед добавлением спросить себя: нужно ли это, чтобы понять, как устроен
  проект и как его запустить? Нет — не добавлять.
