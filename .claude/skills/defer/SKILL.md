# /defer — задача в журнал

1. Поиск дублей: `search_issues` по `repo:grokki91/it_bot is:open label:deferred`
   и ключевым словам. Нашёлся — дописать комментарий, новый не заводить.
2. Завести issue (`issue_write`, labels `deferred`) по шаблону
   `.github/ISSUE_TEMPLATE/deferred.md`. Заголовок — по-русски, что должно
   измениться в поведении. Заполнить:
   - **Что не решено** — одной-двумя фразами;
   - **Что уже известно** — проверенные факты со ссылками `файл:строка`,
     отдельно — непроверенные предположения;
   - **Критерий готовности** — проверяемый: команда и ожидаемый вывод;
   - **С чего начать** — первый шаг и откуда пришло (ветка, PR, сессия).
3. Перед отправкой — секретов нет: логи только после `python3 digest.py scrub`.
4. В ответе — одна строка со ссылкой на issue; больше к пункту в этой
   сессии не возвращаться.

GitHub недоступен — тот же текст отдать пользователю готовым к вставке,
`ИТОГ: OK С ОГОВОРКАМИ`.
